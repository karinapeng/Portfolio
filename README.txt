KARINA PENG PORTFOLIO SOURCE

Open index.html in a browser to view the homepage. The site uses Overpass and DM Mono from Google Fonts, so an internet connection is needed for those fonts.

IMAGE SWAPS
- Homepage portrait: update the src on the IMAGE SWAP comment in index.html.
- Homepage project thumbnails: update the --project-image URL for each project in index.html.
- About illustration: update the src on the IMAGE SWAP comment in about.html.
- Project case-study posters: update each project's image path in the projectData list in script.js.
- Process images: replace the placeholder divs in project.html with img elements; a sample is in the PROCESS IMAGE SWAP comment.
- Put local image files in the assets folder and use paths such as assets/my-image.jpg.

EMAIL AND CONTACT LINKS
- In index.html, about.html, and project.html, look for EDIT EMAIL and EDIT CONTACT LINKS comments.
- Change xxx@gmail.com in both the mailto: URL and the visible email.
- Change each social link's href to your own profile/contact URL.
